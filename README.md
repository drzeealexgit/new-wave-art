# Mattilda Zvolinska — портфоліо / portfolio

Новий двомовний сайт-портфоліо художниці **Матильди Зволінської** (живопис, графіка,
скульптура) з вбудованою адміністративною панеллю. Замінює попередній сайт на Wix:
[maryzvolinskaya.wixsite.com/portfolio](https://maryzvolinskaya.wixsite.com/portfolio).

A new bilingual (EN/UA) portfolio website with a built-in admin panel — no build step,
no server required.

## Швидкий старт

```bash
# варіант 1: просто відкрийте index.html у браузері
# варіант 2 (перевірка з телефона в тій самій мережі):
python3 -m http.server 8080
# → http://<ваш-IP>:8080
```

## Адміністративна панель

* Адреса: `#/admin` (або посилання «Вхід для авторки» у футері)
* Демо-пароль: `tilda-2026` — **змініть його у вкладці «Налаштування»**
* Можливості: створення/редагування/видалення розділів і галерей, завантаження й
  упорядкування медіа, редагування всіх текстів обома мови, експорт/імпорт JSON.
* Зміни зберігаються локально у браузері (localStorage). Для публічної продуктової
  версії зробіть «Експорт даних» і покладіть файл у `data/site-data.json`.

Детальніше: [docs/admin-panel.md](docs/admin-panel.md)

## Структура

```
├── index.html            # сайт + адмін-панель (статичний файл, без збірки)
├── data/site-data.json   # усі тексти й структура (двомовні EN/UA)
├── assets/images/        # зображення робіт (79 шт.)
├── docs/                 # документація: адмінка, схема даних, дизайн, деплой
└── LICENSE.txt
```
