# Дизайн-система «Тиха сила»

Настрій: сила і дух, народжені війною — без жодних військових символів.
Засобом вираження є стриманість, гідність і внутрішній вогонь.

## Палітра
| Токен | HEX | Призначення |
|---|---|---|
| ink (чорнило) | `#1B1713` | текст, темні секції, лайтбокс |
| bone (кістка) | `#F4F0E8` | основне тло |
| bone-2 / bone-3 | `#ECE6D9` / `#FBF9F3` | другорядні тла, рамки робіт |
| stone (камінь) | `#8A8175` | другорядний текст |
| ember (жар) | `#A63A1E` | єдиний акцент |
| line | `#D9D1C1` | волосяні лінії |

## Типографіка
* Cormorant Garamond 500/600 (+italic) — заголовки, назви робіт; Inter 400/500/600 — текст, інтерфейс.
* Обидва з кирилицею, fallback: Georgia / system-ui.
* Ім'я на головній: `clamp(54px, 9vw, 124px)`; заголовок розділу: `clamp(38px, 6vw, 74px)`;
  тіло: 16–17px / 1.75; мікропідписи: 11px, uppercase, letter-spacing 0.2em.

## Сітка і відступи
* Контейнер 1280px; бокові відступи `clamp(20px, 6vw, 96px)`.
* 8pt-шкала: 8/16/24/32/48/64/96/144. Секції: 144px (desktop) / 72px (mobile).
* Роботи: 2 колонки, гутер 24–44px; панорамні роботи — на всю ширину.
* Фото-смуги: CSS-колонки 3 / 2 / 1.

## Рух
* Поява при скролі: IntersectionObserver, 700ms, підйом 16px, стагер 55ms.
* Лайтбокс: 350–450ms, клавіші ← → Esc, лічильник кольору ember.
* `prefers-reduced-motion` вимикає всі анімації.
